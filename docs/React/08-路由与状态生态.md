## React Router（声明式 + 嵌套）

```tsx
import { createBrowserRouter, RouterProvider, Outlet, NavLink } from 'react-router'

function RootLayout() {
  return (
    <>
      <nav>
        <NavLink to="/">首页</NavLink>
        <NavLink to="/users">用户</NavLink>
      </nav>
      <Outlet />
    </>
  )
}

const router = createBrowserRouter([
  {
    path: '/',
    element: <RootLayout />,
    children: [
      { index: true, element: <Home /> },
      {
        path: 'users',
        element: <UsersLayout />,
        children: [
          { index: true, element: <UserList /> },
          { path: ':id', element: <UserDetail /> },
        ],
      },
    ],
  },
])

export function App() {
  return <RouterProvider router={router} />
}
```

## Zustand（主推）

```tsx
import { create } from 'zustand'

type CartState = {
  items: { id: string; qty: number }[]
  add: (id: string) => void
}

export const useCart = create<CartState>((set) => ({
  items: [],
  add: (id) =>
    set((s) => {
      const found = s.items.find((i) => i.id === id)
      if (found) {
        return {
          items: s.items.map((i) =>
            i.id === id ? { ...i, qty: i.qty + 1 } : i,
          ),
        }
      }
      return { items: [...s.items, { id, qty: 1 }] }
    }),
}))

// 组件内：selector 避免无关字段更新导致渲染
function Badge() {
  const count = useCart((s) => s.items.reduce((n, i) => n + i.qty, 0))
  return <span>{count}</span>
}
```

## Redux Toolkit（读码要点）

```ts
import { createSlice, configureStore } from '@reduxjs/toolkit'

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    inc(state) {
      state.value += 1 // Immer
    },
  },
})

export const store = configureStore({
  reducer: { counter: counterSlice.reducer },
})

export const { inc } = counterSlice.actions
export type RootState = ReturnType<typeof store.getState>
```

- 读项目：找 `createSlice`、`createAsyncThunk`、`useSelector`/`useDispatch`。
- 新项目无历史包袱 → 优先 Zustand + Query。

## React Hook Form

```tsx
import { useForm } from 'react-hook-form'

type Values = { email: string; password: string }

function Login() {
  const { register, handleSubmit, formState: { errors } } = useForm<Values>()
  return (
    <form onSubmit={handleSubmit((v) => console.log(v))}>
      <input {...register('email', { required: true })} />
      {errors.email && <span>必填</span>}
      <input type="password" {...register('password', { minLength: 6 })} />
      <button type="submit">登录</button>
    </form>
  )
}
```

- 默认非受控注册，减少重渲染；复杂校验接 Zod + `@hookform/resolvers`。

## 工作约定

- 路由表集中；布局路由管壳子；页面管业务。
- 客户端全局：Zustand；服务端：Query；别混存。
- UI 库按团队规范；表单中后台优先 RHF。
- `NavLink` 的 active class 统一封装成 `MyNavLink`（老项目常见）。

## 踩坑

1. Router v6/v7 API 与旧课 `Switch`/`component` 不同，读文档以现行版为准。
2. Zustand 不写 selector → 任何字段变都渲染。
3. Redux 里存一整份 Query 列表 → 双缓存。
4. RHF 与完全受控 `value`+`onChange` 混用不当导致警告。

## 面试点 / 工作经验点

### Q1：Zustand vs Redux 怎么选型？
**标签**：`面试` `工作经验`

**A**：Zustand：API 薄、样板少、适合多数中前端应用。Redux/RTK：规范强、中间件生态、大型协作与存量项目。新项目默认 Zustand + Query；进 Redux 项目能读 slice 即可。

### Q2：selector 如何防重渲染？
**标签**：`面试` `原理`

**A**：只订阅需要的切片；返回稳定原始值或用浅比较。返回新对象字面量会每次不相等 → 白渲染。RTK 用 `createSelector` 同理。

### Q3：路由嵌套与权限怎么做？
**标签**：`工作经验` `面试`

**A**：鉴权布局包一层 children；未登录 `Navigate` 到 login；角色路由表过滤。也可 loader 鉴权。权限源来自用户 Context/Query。

### Q4：为何 RHF 能减少重渲染？
**标签**：`面试` `原理`

**A**：字段用 ref 注册，输入不必每键触发整表 React state。校验与提交时再汇总。对照：全受控大表单每个 keydown 全树更新。

### Q5：路由 loader 和 TanStack Query 冲突吗？
**标签**：`工作经验`

**A**：不必然。loader 做首屏关键数据；Query 做客户端缓存与交互刷新。或统一 Query，路由只负责参数。团队定一种主路径。

### Q6：和 Vue Router / Pinia 对照怎么讲？
**标签**：`面试`

**A**：嵌套路由、动态段、导航守卫心智接近。Pinia 对 Zustand；Vuex 对 Redux。React 没有官方唯一状态库，生态选择更多。

### Q7：全局弹窗/Toast 放哪？
**标签**：`工作经验`

**A**：轻量 Zustand 或专用库（sonner 等）。别塞进业务 Redux 大对象。

### Q8：UI 库接入常见约定？
**标签**：`工作经验`

**A**：主题 Token 一处配置；按需引入或 tree-shake；表单控件与 RHF 用 Controller 包一层；避免页面直接改组件库源码。
