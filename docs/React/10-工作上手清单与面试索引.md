## 补遗面试点 / 工作经验点

以下为各章未单开、但面试与读码高频的内容。

### Q1：协调（Reconcile）与提交（Commit）两阶段？
**标签**：`面试` `原理`

**A**：Render/协调阶段计算下一棵树（可中断）；Commit 阶段把变更刷到 DOM（偏同步）。理解它有助于解释为何 render 必须纯、副作用放 Effect。

### Q2：Error Boundary 做什么？Hooks 能写吗？
**标签**：`面试` `工作经验`

**A**：捕获子树**渲染**期错误，展示降级 UI。只能用类组件（或库封装）。不捕获事件处理器、异步、Boundary 自身错误。工作中路由级包一层，避免整站白屏。

```tsx
// 使用现成库或类组件；示意 API
<ErrorBoundary fallback={<p>出错了</p>}>
  <Page />
</ErrorBoundary>
```

### Q3：Suspense 解决什么？和 loading 布尔有何不同？
**标签**：`面试` `原理`

**A**：让组件「抛 Promise / 等待」时由最近 Suspense 边界展示 fallback。配合懒加载 `React.lazy`、（及框架数据）流式 UI。比到处 `if (loading)` 更组合。注意：纯 CSR 下数据 Suspense 常需框架或库支持。

### Q4：`React.lazy` + `Suspense` 代码分割怎么说？
**标签**：`工作经验` `面试`

**A**：路由级懒加载减首包。`const Page = lazy(() => import('./Page'))`，外包 Suspense。Next 有自己的 code splitting 与 `loading.tsx`。

### Q5：批量更新（batching）18 前后差异？
**标签**：`面试`

**A**：18 起自动批处理扩展到 Promise/setTimeout 等。要用中间态可 `flushSync`（慎用）。多数业务用函数式更新即可。

### Q6：受控组件「卡住」的经典原因？
**标签**：`工作经验`

**A**：`value` 从 `undefined` 变成有值（或反向）会在受控/非受控间切换告警；应始终传字符串 `value={text}`，初始用 `''`。

### Q7：类组件只读速查（Legacy）
**标签**：`面试` `工作经验`

**A**：读旧码时：`this.state` / `this.setState`；生命周期 `componentDidMount` ≈ `useEffect([])`；`componentDidUpdate` ≈ 带依赖 Effect；`componentWillUnmount` ≈ cleanup。新代码不写 class。`getDerivedStateFromProps` 多数可改为完全受控或 key 重置。

### Q8：`forwardRef` 在 React 19 还要吗？
**标签**：`工作经验`

**A**：函数组件可直接收 `ref` prop，多数场景不再需要 `forwardRef`。维护旧库代码时仍会见到。

### Q9：Portal 事件冒泡 magically 到 React 树？
**标签**：`面试` `原理`

**A**：DOM 上 Portal 节点在 `body`，但 React 事件会沿** React 树**冒泡。做 Modal 点遮罩关闭时仍要注意 `stopPropagation` 场景。

### Q10：如何讲「纯组件 / 纯渲染」？
**标签**：`面试`

**A**：同样 props/state → 同样输出；不在 render 里改外部。不纯会导致 StrictMode、并发下难复现 bug。

### Q11：中间件式请求层怎么设计？
**标签**：`工作经验`

**A**：`fetch` 封装：基址、token、错误码、刷新登录。Query 的 `queryFn` 只调该封装。对齐你在 Vue/Axios 拦截器上的经验。

### Q12：微前端 / 多实例 React 注意？
**标签**：`工作经验`

**A**：多副本 React 导致 Hooks 报错；共享 singleton；样式隔离；路由 base 配置。出现「Invalid hook call」先查是否多 React。

### Q13：测试你会测什么？
**标签**：`面试` `工作经验`

**A**：纯函数与 reducer；组件用 Testing Library 测用户行为而非实现细节；Query 用 `QueryClient` 包装。少测快照糊墙。

### Q14：可访问性最低标准？
**标签**：`工作经验`

**A**：按钮用 `button`；表单有 label；弹层焦点陷阱与 Esc；键盘可操作。UI 库能帮一半，业务别用 `div` 冒充按钮。

### Q15：口述一道综合题：列表页如何分层？
**标签**：`面试` `工作经验`

**A**：路由参数 → Query（`queryKey` 含筛选分页）→ 展示组件；筛选表单本地 state 或 URL search；行内操作 mutation + invalidate；权限在布局；虚拟列表按需。状态不进 Redux 除非跨页复杂共享。
